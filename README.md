# SIMS SMK

Fondasi Sistem Informasi Manajemen Sekolah (SIMS-00).

```bash
npm install
npm run db:up
npm run db:migrate
npm run db:seed
npm run dev
```

Web: http://localhost:5173  
API: http://localhost:3001

Akun development ada di `apps/api/.env` (`SEED_OWNER_EMAIL` / `SEED_OWNER_PASSWORD`).
